Frequently Asked Questions

When a citizen reports an issue, the system calculates the great-circle distance between the incoming GPS coordinate and all active tickets of the same category using the Haversine formula. If the distance is ≤ 100 metres, it merges the report into the existing master ticket, increments its corroboration count, and raises the priority score instead of spawning redundant work orders.
The priority score is computed on a 0–100 scale using the transparent formula:
Priority = min(100, (Severity × 10) + (Report Count × 5) + (Upvotes × 2)).
Issues scoring ≥ 80 points are automatically classified as Critical, ensuring that high-severity hazards corroborated by multiple citizens receive immediate crew dispatch.
Each category is bound to a strict statutory deadline (24 hours for water leaks/garbage, 36h for streetlights, 48h for potholes, 72h for footpaths). If a ticket remains unresolved past this timeframe, it automatically displays an animated ⚠️ SLA Breached alert on both public tracking and executive consoles.
