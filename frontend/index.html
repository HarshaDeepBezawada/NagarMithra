Frequently Asked Questions

This platform is dedicated exclusively to the Mangalagiri municipal jurisdiction in Andhra Pradesh. By concentrating on this specific service boundary, the municipal administration can enforce rapid statutory response times (24–72 hours) and prevent duplicate work orders across local neighborhoods.
When you select a location via map click, search, or GPS, the backend uses an authoritative GeoJSON polygon of Mangalagiri. It casts an imaginary horizontal ray from the coordinate; if the ray intersects an odd number of polygon edges, the point lies safely inside Mangalagiri. Otherwise, submission is blocked with an informative message.
If an active grievance of the same category is reported within 100 metres of an existing ticket, it automatically merges into the master work order, increments its citizen corroboration count, and increases the priority score.
